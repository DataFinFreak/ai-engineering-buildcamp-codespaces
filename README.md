# ai-engineering-buildcamp-codespaces
Course work for AI Bootcamp: From RAG to Agents, plus my own projects.

## Projects

- [**RAG over RBI Financial Stability Reports**](Code/projects/rbi-fsr-rag/): a RAG pipeline over four
  RBI Financial Stability Reports (732 pages), and why it confidently gave the wrong year. Covers keyword
  retrieval failures, structured output and a small evaluation set.

## Contents

- `Code/01-foundation/`, `Code/02-rag-usecases-tech/`: course notebooks, by module
- `Code/03-agents/`: agent basics (tool calls, Q&A loop) and agent frameworks (toyaikit, Pydantic AI)
- `Code/projects/`: my own projects
- [`LEARNING-RESOURCES.md`](LEARNING-RESOURCES.md): videos, docs and books for each concept,
  mapped to the notebook section that uses it
